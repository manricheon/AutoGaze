# Action Recognition with AutoGaze

This guide explains how to evaluate AutoGaze on action recognition tasks, both in zero-shot MCQ format and using dedicated classification models.

---

## 1. Supported Benchmarks (지원 벤치마크)

We support two primary ways to evaluate action recognition:

### A. MCQ Format (객관식 평가)
Traditional action recognition tasks are converted into 4 or 5-choice questions. This is the preferred way for MLLMs.

- **MVBench (Action Recognition subtask)**: Comprehensive 20-task benchmark.
- **ActionAtlas**: Fine-grained sports action recognition (~2 GB).
- **NExT-QA**: Causal and temporal action reasoning.

### B. Dedicated Classification (분류 모델 평가)
Using a Vision Encoder + Task Decoder to predict the class label directly.

- **Kinetics-400**: Standard action recognition benchmark.
- **UCF-101 / HMDB-51**: Classic small-scale benchmarks.

## 2. Evaluation Commands (평가 명령어)

### MCQ Benchmarking (AutoGaze ON/OFF)
Use `run_benchmark.py` to compare accuracy with and without AutoGaze.

```bash
# ActionAtlas (AutoGaze ON)
python -m autogaze.eval.run_benchmark \
    --task actionatlas \
    --mllm nvila \
    --gazing-ratio 0.25 \
    --output results/actionatlas_ag025.json

# ActionAtlas (AutoGaze OFF)
python -m autogaze.eval.run_benchmark \
    --task actionatlas \
    --mllm nvila \
    --no-autogaze
```

### Qualitative Comparison (Action Recognition)
Use `run_cv_tasks.py` to visualize how AutoGaze affects top-K predictions for action recognition models (e.g., VideoMAE-CLS).

```bash
python scripts/run_cv_tasks.py \
    --input assets/example_input.mp4 \
    --tasks videomae_cls \
    --ag-ratio 0.25
```

## 4. Architectural Integration (아키텍처 통합)

For classification tasks, we use the `RecognitionDecoder` which applies **Gaze-weighted Pooling**.

**Pipeline**:
1. **Vision Encoder**: Extracts features from selected patches.
2. **Gaze-weighted Pool**: Tokens selected by AutoGaze contribute more to the final video representation.
3. **MLP Head**: Predicts the action class.

See `autogaze/decoders/recognition.py` for the implementation.
