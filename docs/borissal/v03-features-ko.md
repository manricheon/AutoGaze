# Borissal v0.3 — 핵심 특징 해설 (한글)

> 대상 독자: v0.3을 쓰거나 평가하려는 사람. "무엇이 왜 들어갔고, 무엇이
> 왜 빠졌는가"를 결과 수치와 함께 한 장으로 설명한다. 정밀한 판정
> 기록은 `design.md`, 설계 계약은 `v03-design.md`, 노브 목록은
> `reference.md` 참조. 기준 성적은 held-out InternVid 16클립,
> 마지막 갱신 2026-07-19.

## 한 줄 요약

v0.3은 **"고전 saliency 아이디어 후보 뱅크(9+4개)를 만들고, 정량
게이트(semantic recall 주 지표)로 조합을 탐색해, 이긴 6개만 채택한"**
비학습 패치 선택기다. 결과: **semantic recall 0.325 → 0.354** (ratio
0.25; ratio 0.5에선 0.560 → 0.577), V-JEPA coverage/uniqueness **동시
개선**, CPU **~22ms/클립**. (참고: 파일럿 규모의 학습형 v1은 아직 이
기준선에 못 미치지만, 그것은 소규모 파일럿과의 비교일 뿐이다 —
공정한 학습형 대비는 스케일 런 이후에 성립한다.)

## 채택된 6가지 특징 (기여 순)

| # | 특징 | 무엇을 하나 | 왜 description에 좋은가 | 단독 기여 |
|---|---|---|---|---|
| 1 | **피크 촉진 융합** (Itti N(·)) | 채널 맵마다 "(최대값 − 국소최대 평균)²" 배율을 tubelet별로 계산해, 피크가 뚜렷한 맵은 승격하고 화면 전체에 발화하는 맵은 강등 | 텍스처가 그라디언트 채널을 범람시키는 순간, 그 채널의 발언권 자체가 줄어든다 — 채널 수준의 자동 노이즈 방어 | 16클립 중 13승 3패, +0.015 |
| 2 | **coherence 텍스처 게이트** | 구조텐서 고유값 비로 "한 방향 결"(반복 무늬·직선 엣지)을 검출해 그라디언트 채널에서 억제. 곱을 먼저 만들고 4×4 블록 평균으로 축소(ds=4)해 60ms→5ms | 벽돌·격자·수풀 같은 배경 텍스처에 낭비되던 예산이 객체로 이동 | 12승 4패, +0.012 |
| 3 | **DoG blob 채널** | 다중 스케일 박스블러 차분으로 객체 **내부**를 발화시키는 3번째 채널 (그라디언트는 경계만 봄) | 캡션은 "빨간 셔츠의 남자"처럼 객체 단위 — 실루엣만이 아니라 몸통 패치가 있어야 인식된다 | 9승 7패, +0.010 (gist 최대 +0.02) |
| 4 | **pool 블록 게이트** | coarse 블록 선택을 "1/2 해상도로 파이프라인 재실행" 대신 "fine 점수 블록 평균"으로 — 파이프라인 2회 → 1회 | 품질 무손실 효율화: 16클립 전체에서 선택이 재계산 방식과 **완전 동일**, 지연 −7ms | 0승 0패 16동 (동일), −7ms |
| 5 | **프레임 단위 spatial** (max 집계) | 엣지 신호를 2프레임 평균이 아닌 원본 프레임마다 계산 후 max 집계 — 빠른 움직임의 모션 블러로 반토막 나던 디테일 보존 (게이트는 tubelet 단위 유지로 +6ms에 억제) | 빠르게 움직이는 피사체의 선명한 순간을 잡는다 | 8승 6패 2동, +0.003 (**채택 중 최약 마진 — 스케일 재확인 대상**) |
| 6 | **(v0.2 유지) global 할당 + floor** | 클립 전체 top-K로 "액션 있는 순간"에 예산 집중 + tubelet당 최소 보장으로 공백 방지 | 설명은 사건 중심 — 정보가 몰린 순간이 더 받아야 하고, 조용한 구간도 완전히 비면 안 된다 | v0.2 게이트에서 단독 최대 기여 |

계산 순서 요약: luma/tubelet → 모션(frame-diff) + 엣지(프레임 단위,
coherence 게이트) → 패치 풀링 → 노이즈 플로어 → DoG 채널 합류 →
피크 촉진 융합(지역/전역 블렌드) → global 할당 + pool 블록 게이트 →
top-k → 오름차순 keep_index (V-JEPA 계열에 무재배열 부착).

## 기각된 후보와 이유 (negative results — 전부 off-기본 노브로 남음)

- **motion center-surround** (4승 12패): InternVid엔 카메라 팬이 적어
  "균일 모션 상쇄"가 정보성 모션만 깎았다. 팬 많은 도메인용 노브로 보존.
- **image signature** (8승 7패 + cov/uniq 동시 열화): DoG와 역할이 겹치고
  판별력이 동전 던지기 수준.
- **색 희소성** (체인 위 6승 10패, +7.5ms): 단독으로는 uniqueness 최대
  이득(+0.114)이었으나 체인에선 주 지표가 하락. uniqueness가 필요해지면
  1순위 재시도 후보 (dog_blob 대체로 시도 권장).
- **엔트로피 융합**: 실클립에서 사실상 항등 (이론상 카메라 폴백이
  실데이터에서 발화하지 않음).
- **점수 EMA / 선택 hysteresis**: 시간 안정성은 얻지만 늦게 등장하는
  객체의 recall을 깎아 "recall 비열화" 채택 조건 위반. 스트리밍 UI
  용도로만.
- **할당 상한 2×**: 이 데이터에선 한 번도 발동 안 함 (블록 게이트가
  이미 노출 상한 역할) — 안전 노브.

## 사용법

```python
from autogaze.models.borissal import Borissal, BorissalConfig
model = Borissal(BorissalConfig.v0_3())          # 배포 프리셋
sel = model.select(video, gazing_ratio=0.5)      # 운영 범위 0.25~0.5
# description 파이프라인에 넘길 것: sel.keep_index (오름차순, -1 패딩)
```

ratio 0.5에서 권장 확인 모드: 기본(global) / `spread_fraction=0.25`
(시공간 뼈대 보장 — gist·recon 회복) / uniform(대조용). 도메인 노브:
시네마틱 콘텐츠는 `center_bias`, 팬 많은 영상은
`motion_center_surround` 재고.

## 알려진 한계 / 다음 단계

- 카메라 모션 축은 이 평가셋으로 판정 불가 (팬 부족) — 팬 많은 셋에서
  `gme`/`motion_cs` 재심 필요.
- 프레임 단위 spatial의 마진(+0.003)은 스케일 런에서 재확인.
- 시간 예산 분배는 규칙 기반(global+floor)까지만 탐색됨 — 학습형
  할당(E5, `v03-design.md` §7.5)이 다음 단계.
- v1(학습형)은 아직 v0.3의 풍부해진 입력 뱅크로 재학습되지 않았다.
