v0.6 처리 파이프라인

디코딩된 프레임에서 어느 패치를 다운스트림에 넣을지까지, v0.6 프리셋이 실제로 실행하는 전체 경로. 모든 값은 BorissalConfig.v0_6()에서 읽은 실측값이고, 단계 순서는 modeling_borissal.py의 실행 순서와 일치한다 — 이 라인에서 순서는 스펙의 일부다.

v0.6 = v0.5 + { luma_mode="bt601", laplacian_gate, static_guard, keyframe_prior, center_bias=0.3 } + per_frame_allocation: "uniform" → "global" v0.5 = v0.3 + { score_coarsen=2 (cube), motion_weight="auto", coherence_at_grid, spatial_diff="tubelet" } v0.3 = 채택된 후보 조합 { fusion_norm="peak", coherence_gate(ds=4), dog_blob_weight=0.5 } 계보 주의: v0.5는 v0.4가 아니라 v0.3 위에 있다 → v0.6의 motion_diff_stride = 1 (프레임률 보정 없음)

§1단계별 상세

16프레임 · 384px 입력 기준. 그리드는 (T/tubelet, H/patch, W/patch) = (8, 24, 24) = 4,608 패치, 병합 전 토큰 기준.

  1. 00
    디코드 · 리사이즈 · 그리드 확정
    정사각 리사이즈 후 H % patch == 0, T % tubelet == 0을 강제한다. 이 divisibility 가드가 patch14 고정해상도 타워(384 % 14 ≠ 0)를 거부하는 지점이기도 하다.
    video (B, 16, 3, 384, 384) → grid_thw = (8, 24, 24)
    scale 384 · patch_size 16 · tubelet_size 2 · gazing_ratio 0.5 기본
  2. 01
    BT.601 lumav0.6 신규
    v0.5까지는 RGB 단순 평균이었다. v0.6은 0.299R + 0.587G + 0.114B로 지각 밝기에 맞춘다 — saliency-v3.1 stage 1의 유일한 미포팅 요소였던 항목. 이후 모든 신호가 이 luma에서 파생되므로 가장 근본 위치의 변경이다.
    이어서 튜블렛 평균으로 시간축을 절반으로 접는다.
    gray (B, 16, H, W) → tub (B, 8, H, W)
    luma_mode = "bt601"
  3. 02
    모션 경로 — 프레임 차분시간
    튜블렛 평균을 차분하면 튜블렛 내부의 빠른 움직임이 상쇄되므로, 프레임 단위로 차분한 뒤 튜블렛별로 평균 집계한다. 코덱 residual의 프록시.
    stride = 1에 주의: 프레임률 보정(v0.4의 "auto")은 v0.6에 들어있지 않다. v0.5가 v0.3 위에 세워졌기 때문이며, 32프레임 입력에서 모션 신호가 약해지는 성질이 그대로 남아 있다.
    |f_t − f_{t−stride}| → group by tubelet → mean → motion (B, 8, H, W)
    motion_diff = "frame" · motion_diff_stride = 1 · frame_diff_agg = "mean" · motion_smooth_kernel off
  4. 03
    공간 경로 — 그라디언트공간
    튜블렛 평균 위에서 전진차분 dx, dy → √(dx²+dy²). 프레임 단위 재계산(spatial_diff="frame")은 +0.003 recall에 +8ms여서 큐브 coherence 아래선 무의미하다고 판정되어 튜블렛으로 되돌렸다.
    spatial (B, 8, H, W)
    spatial_op = "grad" · spatial_diff = "tubelet"
  5. 04
    픽셀 → 패치 풀링
    16×16 평균 풀링으로 두 맵을 패치 그리드로 내린다. 이후 모든 연산은 그리드 해상도다.
    motion_p, spatial_p (B, 8, 24, 24)
    pooling = "avg" · kernel = stride = 16
  6. 05
    coherence 게이트곱셈
    구조텐서 coherence ((a−c)² + 4b²)/(a+c+ε)²로 grad × (1−coh)^γ. 반복 격자무늬·긴 직선 엣지는 coherence가 최대라 억제되고, 다방향 미세구조를 가진 객체 내부는 살아남는다. eigen decomposition 없는 닫힌형.
    v0.5부터 그리드 해상도에서 계산해 풀링된 맵에 곱한다 — 픽셀 해상도 곱셈·업샘플 경로 대비 약 10ms → 1ms, 선택 IoU 0.923.
    spatial_p ← spatial_p × coherence_gate_grid(dx, dy)
    coherence_gate = True · coherence_at_grid = True · coherence_gamma = 1.0 · coherence_kernel = 5 · downsample = 4
  7. 06
    모션 노이즈 플로어시간
    튜블렛별 중위값을 노이즈 추정치로 삼아 relu(motion_p − τ). 진짜 모션은 공간적으로 희소하므로 튜블렛 전체의 중위값은 정지 패치가 지배한다 — 코덱의 dead-zone 양자화와 같은 발상. topk로 구현해 sort/quantile을 피한다(모바일 안전).
    순서가 중요: min-max 정규화보다 앞이어야 한다. 뒤면 저모션 튜블렛에서 노이즈 플로어가 다시 [0,1] 전체로 증폭된다. auto 가중치보다도 앞이어야 w가 노이즈 보정된 값을 본다.
    τ = q50(motion_p) per tubelet → motion_p ← relu(motion_p − 1.0·τ)
    motion_noise_floor = "quantile" · motion_noise_q = 0.5 · motion_noise_scale = 1.0
  8. 07
    auto 가중치 — appearance-first
    w = E[motion] / (E[motion] + E[spatial]). 정규화 이전의 절대 크기에서 계산해야 의미가 있다(정규화된 맵은 절대 크기를 지워버린다). 32프레임 실측 w ≈ 0.34, 정적 클립 ≈ 0.03 — 모션이 적을수록 자동으로 객체·텍스트 쪽으로 기운다.
    이 값이 v0.5의 "appearance-first" 결정이다: 다운스트림 인코더가 시간 모델(V-JEPA)이면 모션은 중복이므로, 셀렉터는 인코더가 발명할 수 없는 appearance를 지켜야 한다.
    w : scalar per clip (B, 1, 1, 1)
    motion_weight = "auto"
  9. 08
    정규화 · 채널 융합+ DoG
    채널별 per-tubelet min-max 후 fused_blend로 가중 결합. fusion_norm="peak"은 Itti의 N(·) 피크 촉진 — 화면 전체에 고르게 발화하는 맵은 융합 가중치가 깎인다(맵 수준 텍스처 억제 + 공짜 카메라 폴백).
    세 번째 채널 DoG blob(가중치 0.5)이 여기 합류한다 — avgpool 피라미드 차분의 스케일 최대값으로, 그라디언트가 0인 객체 내부를 채운다. signature와 color_rarity는 가중치 0으로 비활성.
    S = fused_blend[(w, motion_n), (1−w, spatial_n), (0.5, dog_n)] → (B, 8, 24, 24)
    fusion_norm = "peak" · fusion_entropy_floor = 0.3 · dog_blob_weight = 0.5 · signature_weight = 0 · color_rarity_weight = 0
  10. 09
    local / global 정규화 혼합
    per-tubelet min-max는 튜블렛을 서로 평등하게 만들어 버린다. 클립 전역 min-max 성분을 섞어 튜블렛 간 크기 차이를 보존한다 — global 할당이 의미를 가지려면 필수다. 고에너지 순간이 클립 전체에서 더 높게 랭크될 수 있어야 하기 때문.
    S ← 0.7·S_local + 0.3·S_global
    score_norm_blend = 0.7
  11. 10
    Laplacian 텍스처 게이트v0.6 신규곱셈
    R = |lap(motion)| / motion의 시그모이드 억제. 구조텐서 coherence와 다른 메커니즘(2차 미분 에너지 대 모션 비율)이다. 정규화 이전 풀링 모션 맵을 써서 R이 크기 의미를 갖게 한다.
    ⚠️ 프록시상 회귀했다(recall 0.299 vs v0.5 0.343, 3W-13L) — coherence 게이트가 이미 텍스처를 억제하는데 두 번째 억제기를 겹쳐 과하게 깎는다는 해석. 그럼에도 켜져 있는 이유는 saliency-v3.1의 다운스트림 검증을 프록시보다 신뢰한 결정이다.
    S ← S × sigmoid(−(R − r0)/tau)
    laplacian_gate = True · laplacian_gate_r0 = 1.0 · laplacian_gate_tau = 0.5
  12. 11
    정적 appearance 가드v0.6 신규
    국면 전환(regime switch)이 핵심이다. v0.5는 appearance를 전역 motion_weight로만 섞지만, 여기서는 튜블렛이 정지일 때만 국소적으로 엣지 에너지를 되돌려준다: s_t = sigmoid((thresh − m̄_t)/tau)를 전역 정규화된 모션에 적용하고 |lap(luma)|를 가산. 모션이 큰 튜블렛은 s_t ≈ 0이라 무영향.
    문서·텍스트·정지 샷이 top-k에서 살아남게 한다. v0.6 세 노브 중 프록시에서 유일하게 이긴 것(recall +0.012, gist +0.017, 8W-7L).
    S ← S + 0.5 · minmax(s_t · |lap(luma_grid)|)
    static_guard = True · static_guard_weight = 0.5 · thresh = 0.05 · tau = 0.02
  13. 12
    기계적 GOP 키프레임 priorv0.6 신규
    배포 시 셀렉터는 이미 디코딩된 프레임만 받고 코덱 메타데이터가 없다. 그래서 키프레임 구조를 픽셀·인덱스만으로 근사한다: gop=8 주기 pseudo-keyframe(순수 인덱스 산술, trace/ONNX 안전) + luma 점프에 대한 sigmoid soft 장면전환 가중치(데이터 의존 분기 없음).
    효과가 두 갈래다 — (1) 해당 튜블렛에 엣지 점수 가산, (2) 예산 재분배. 단 (2)는 uniform 할당에서만 동작하는 경로이고, v0.6 기본값은 global이므로 점수 상승이 global top-k를 통해 자연히 예산을 끌어간다.
    kf = max(periodic, scene_soft) → S ← S + 0.5 · minmax(kf · |lap(luma)|)
    keyframe_prior = True · keyframe_gop = 8 · keyframe_weight = 0.5 · keyframe_alloc_boost = 1.0 · scene_thresh = 2.0 · scene_tau = 0.5
  14. 13
    center biasv0.6 재활성
    고전 구도 prior. 그리드 해상도 상수 가우시안(σ=0.45)을 가산하므로 비용은 무시 가능. v0.2 이후 꺼져 있었다.
    ⚠️ 프록시상 회귀(recall −0.030, gist −0.032). InternVid 피사체가 중앙에 없는 경우가 많아 구도 prior가 헛발질한다는 해석 — 데이터/도메인 불일치이지 반박은 아니다.
    S ← S + 0.3 · exp(−(h² + w²)/(2·0.45²))
    center_bias = 0.3
  15. 14
    큐브 coarsen — 선택 단위 확정
    점수를 12×12로 풀링하고 repeat_interleave로 되돌려, 모든 2×2 블록이 같은 점수를 공유하게 한다. top-k가 흩어진 미세 패치 대신 온전한 2×2 큐브를 고르므로 캡셔너가 grounding하기 쉬운 객체 덩어리가 남는다. 블록 게이트(block_size)를 대체했고 coherence 0.769로 동등하나 더 강하게 강제된다.
    다운스트림 어태치의 핵심: 이 2×2 단위가 Qwen3-VL/3.5의 spatial_merge_size=2 병합 토큰과 정확히 일치한다. 그래서 리맵 없이 1:1로 붙는다.
    S ← repeat_interleave(avgpool(S, 2), 2) — 토큰 그리드는 24×24 유지
    score_coarsen = 2 · block_size = 1 (게이트 비활성)
  16. 15
    예산 할당 — global + floor
    클립 전역 top-K_total에 튜블렛별 최소 보장 m을 둔다. 예산은 움직임이 있는 곳으로 모이고, floor가 시간 커버리지를 지킨다(빈 튜블렛 없음). v0.6이 uniform에서 global로 바꾼 이유는 saliency-v3.1의 stage 7(클립 전역 top-K + min-1 floor)이 곧 content-adaptive 할당이기 때문이다.
    coarse-to-fine 게이트는 튜블렛당 uniform 몫의 2배까지만 노출한다 — 최악 용량을 그대로 쓰면 게이트가 거의 열려 coherence가 무력화된다(경험적 발견).
    K_total = round(ratio·L) · m = max(1, round(0.25·K_total/T_grid)) · k_gate = min(N_pf, 2·⌈K_total/T_grid⌉)
    per_frame_allocation = "global" · min_keep_per_frame_ratio = 0.25 · max_keep_per_frame_mult = 0 · spread_fraction = 0
  17. 16
    top-k · 패킹
    보장분을 먼저 확정하고 남은 자유 예산을 전역 top-k로 채운 뒤, 마스크를 오름차순 keep_index로 패킹한다. 정렬 계약은 다운스트림이 각 토큰을 원래 (t, row, col)로 되돌리는 근거이므로 불변이다. 키가 유일하도록 구성해 stable sort 없이 plain argsort를 쓴다(ONNX 제약).
    keep_index (B, K) 오름차순 · −1 패딩 · per_frame_keep (B, 8)
    _pack_gazing_mask · 예산 정확성: sum(per_frame_keep) == num_keep
  18. 17
    다운스트림 계약
    Selection은 grid_thw-native이고, 소비자별 변환은 어댑터가 담당한다 — Qwen3-VL 병합 토큰, V-JEPA keep-index gather, AutoGaze/NVILA gazing_pos dict, 멀티스케일 VideoMAE, per-frame SigLIP 인덱스.
    Selection{ grid_thw, scores, keep_mask, keep_index, keep_coords, num_keep, per_frame_keep }
    adapters.to_qwen3vl_video_tokens · to_vjepa2 · to_autogaze_gazing_info · to_videomae_gazing_info · to_onevision_frame_indices

§2순서 규칙 — 왜 순서가 스펙인가

바꾸면 조용히 망가지는 인접 관계

  • 노이즈 플로어는 min-max 정규화보다 앞. 뒤로 가면 저모션 튜블렛에서 노이즈가 [0,1] 전체로 재증폭된다.
  • auto 가중치는 정규화보다 앞. 정규화된 맵은 절대 크기를 지우므로 에너지비가 무의미해진다.
  • center-surround는 노이즈 플로어보다 앞(v0.6에선 비활성). center-surround 먼저, dead-zone 다음.
  • fusion_norm은 quantile floor 뒤. 노이즈 스파이크 하나가 피크 촉진을 이기지 못하게.
  • v0.6 게이트·prior는 큐브 coarsen보다 앞. 12×12 풀링이 정제된 점수를 받아야 한다.
  • 채널별 정규화는 시간 EMA보다 앞(v0.6에선 EMA 비활성). raw 스케일 맵을 EMA하지 않는다.
