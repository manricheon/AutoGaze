# Video QA Benchmark Guide (비디오 QA 벤치마크 가이드)

This guide explains how to evaluate **AutoGaze + MLLM** pipelines on standard video QA benchmarks, focusing on comparing performance with and without AutoGaze.

이 가이드는 표준 비디오 QA 벤치마크에서 **AutoGaze + MLLM** 파이프라인을 평가하고, AutoGaze 사용 여부에 따른 성능 비교 방법을 설명합니다.

## 1. Core Benchmarking Method (평가 방법론)

We use **Multiple Choice Question (MCQ)** datasets to measure model understanding. The evaluation script calculates accuracy by comparing the model's predicted option (e.g., 'A') with the ground truth.

우리는 모델의 이해도를 측정하기 위해 **객관식 질문(MCQ)** 데이터셋을 사용합니다. 평가 스크립트는 모델이 예측한 보기(예: 'A')와 정답을 비교하여 정확도를 계산합니다.

## 2. Comparing AutoGaze ON vs. OFF (ON/OFF 비교 테스트)

To measure the "AutoGaze effect," you should run two evaluations for each task: one with the default settings (ON) and one with the `--no-autogaze` flag (OFF/Baseline).

AutoGaze의 효과를 측정하려면 각 태스크에 대해 두 번의 평가를 실행해야 합니다: 기본 설정(ON)과 `--no-autogaze` 플래그를 사용한 설정(OFF/기준선).

### A. Automated Comparison (자동 비교 실행)
The easiest way is to use the master script, which runs both modes sequentially and prints a summary table.
가장 쉬운 방법은 두 모드를 순차적으로 실행하고 요약 표를 출력하는 마스터 스크립트를 사용하는 것입니다.

```bash
# Run all benchmarks with NVILA (AutoGaze ON + OFF)
bash scripts/run_benchmarks.sh --tasks videomme,mvbench --max-samples 100
```

### B. Manual Comparison (수동 실행)
You can run individual tasks using the Python module.

#### **Case 1: AutoGaze ON (Integrated/Full)**
```bash
python -m autogaze.eval.run_benchmark \
    --task videomme \
    --mllm nvila \
    --gazing-ratio 0.75 \
    --output results/videomme_ag075.json
```

#### **Case 2: AutoGaze OFF (Baseline)**
```bash
python -m autogaze.eval.run_benchmark \
    --task videomme \
    --mllm nvila \
    --no-autogaze \
    --output results/videomme_baseline.json
```

## 3. Measuring the "AutoGaze Effect" (효과 측정 지표)

When comparing results, look at three key metrics:
결과를 비교할 때 다음 세 가지 핵심 지표를 확인하세요:

| Metric (지표) | Goal (목표) | Note (비고) |
| :--- | :--- | :--- |
| **Accuracy (%)** | **Maintain** | Accuracy should remain nearly identical to the baseline. (정확도는 기준선과 거의 동일하게 유지되어야 함) |
| **Latency (ms)** | **Reduce** | Full Mode should show 2x-4x speedup. (Full 모드에서 2~4배 속도 향상 필요) |
| **VRAM (GB)** | **Reduce** | Memory usage should drop due to fewer tokens. (토큰 수 감소로 메모리 사용량 절감) |

## 5. Troubleshooting (문제 해결)

- **Out of Memory?**: If you hit OOM during the baseline (OFF) run, try reducing `--num-frames`. AutoGaze (ON) usually requires much less memory.
- **Accuracy Drop?**: If accuracy drops significantly (>2%), ensure you are using the correct `--model-path` for the runner.
- **HLVid Task**: Remember that HLVid requires local video files. Run `bash scripts/download_hlvid.sh` first.
